
# Enterprise SOC Home Lab

## Overview

This repository documents the design, deployment, and operation of my Enterprise Security Operations Center (SOC) Home Lab built using Proxmox VE.

The lab simulates a small enterprise network consisting of Windows and Linux systems, centralized logging, intrusion detection, endpoint monitoring, and attack simulation.

---

## Lab Components

- Proxmox VE
- Ubuntu Server 24.04
- Windows Server 2022
- Active Directory Domain Services
- Windows 10 Client
- Kali Linux Attacker
- Zeek Network Security Monitor
- Suricata IDS
- Wazuh SIEM
- Wazuh Agents
- Security Onion
